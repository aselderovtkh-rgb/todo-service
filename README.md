# Todo Service

Простой сервис списка задач на FastAPI. Позволяет создавать задачи, смотреть их список (в том числе только выполненные или невыполненные), отмечать задачу выполненной и удалять её.

**Для кого:** для одного человека, которому нужен минимальный API для ведения личного списка дел. Также проект служит учебным примером полного пути сервиса: код → Git → тесты → CI.

Задачи хранятся в памяти процесса: после перезапуска список очищается. База данных не нужна.

Основа: учебный пример `app_final.py` с занятий. В нём заменены тема и маршруты, а также добавлены собственная логика, параметры, настройки через переменные окружения, тесты и логи.

## Маршруты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/` | Приветствие и ссылка на документацию |
| GET | `/health` | Проверка работоспособности, возвращает `{"status": "ok"}` |
| GET | `/version` | Название и версия приложения |
| GET | `/tasks` | Список задач; фильтр `?done=true` / `?done=false` |
| POST | `/tasks` | Создать задачу, тело запроса: `{"title": "Купить молоко"}` |
| GET | `/tasks/{task_id}` | Получить задачу по id (если её нет, вернётся 404) |
| POST | `/tasks/{task_id}/done` | Отметить задачу выполненной |
| DELETE | `/tasks/{task_id}` | Удалить задачу |
| POST | `/tasks/{task_id}/undo` | Вернуть выполненную задачу в работу |
| GET | `/stats` | Статистика: всего, выполнено, открыто |

## Установка

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/<ваш-логин>/todo-service.git
cd todo-service

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements-dev.txt
```

`requirements.txt` содержит зависимости для работы приложения, а `requirements-dev.txt` дополнительно включает зависимости для тестов.

## Переменные окружения

Все переменные необязательные: если их не задать, используются значения по умолчанию. Пример лежит в `.env.example`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `APP_NAME` | `Todo Service` | Название сервиса (видно в `/version` и `/docs`) |
| `APP_VERSION` | `1.0.0` | Версия, которую отдаёт `/version` |
| `LOG_LEVEL` | `INFO` | Уровень логов: `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `MAX_TASKS` | `100` | Максимальное количество задач |

Задать переменную при запуске можно так:

```bash
# macOS / Linux
MAX_TASKS=5 LOG_LEVEL=DEBUG uvicorn app_final:app

# Windows (PowerShell)
$env:MAX_TASKS="5"; uvicorn app_final:app
```

Файл `.env` не попадает в репозиторий (он указан в `.gitignore`). Секретов у приложения нет.

## Запуск

Для обычной работы запускайте без `--reload`:

```bash
uvicorn app_final:app --host 127.0.0.1 --port 8000
```

Для разработки можно использовать режим с автоперезагрузкой:

```bash
uvicorn app_final:app --reload
```

После запуска интерактивная документация доступна по адресу http://127.0.0.1:8000/docs. Там можно вызвать любой маршрут кнопкой «Try it out».

## Тесты

```bash
python -m pytest -v
```

Тесты проверяют `/health`, `/version`, создание и получение задач, ошибку 404 для несуществующей задачи, фильтр по статусу и отказ при пустом названии.

Тесты также запускаются автоматически в GitHub Actions (`.github/workflows/ci.yml`) при каждом push и pull request. После успешных тестов workflow сохраняет artifact `todo-service` с файлами приложения. Его можно скачать на странице запуска во вкладке Actions.

## Диагностика

**Проверить, что сервис жив:**

```bash
curl http://127.0.0.1:8000/health
# {"status":"ok"}

curl http://127.0.0.1:8000/version
# {"name":"Todo Service","version":"1.0.0"}
```

Эти адреса можно открыть и прямо в браузере.

**Где смотреть логи:** логи выводятся в терминал, в котором запущен `uvicorn`. Пример:

```
2026-10-24 13:30:00 INFO todo: Запуск Todo Service v1.0.0 (MAX_TASKS=100)
2026-10-24 13:30:05 INFO todo: Создана задача id=1: Купить молоко
2026-10-24 13:30:09 WARNING todo: Задача id=999 не найдена
```

Чтобы видеть больше подробностей, запустите сервис с `LOG_LEVEL=DEBUG`.

**Частые проблемы:**

| Симптом | Причина и решение |
|---|---|
| `ModuleNotFoundError: No module named 'fastapi'` | Не активировано окружение или не установлены зависимости. Выполните `pip install -r requirements-dev.txt` |
| `address already in use` | Порт 8000 занят. Запустите с `--port 8001` |
| `/tasks/abc` возвращает 422 | id должен быть числом |
| `POST /tasks` возвращает 400 | Достигнут лимит задач `MAX_TASKS` |
| После перезапуска задачи пропали | Это ожидаемо: задачи хранятся в памяти |
